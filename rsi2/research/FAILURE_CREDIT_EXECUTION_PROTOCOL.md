# Grouped public-failure credit: execution registration

This is the executable, deliberately limited grouped component probe for
`FAILURE_CREDIT_PROTOCOL.md`. It does not replace the original RSI criteria,
eight-generation experiment, learned-library requirement or untouched final
evaluation. No VALID, TEST or audit partition is acquired.

## Frozen scope

The name-only manifest `FAILURE_CREDIT_GROUPS.json` was produced before this
probe's performance was read. Family is the name before the first ` with `;
SHA-256 of its UTF-8 bytes interpreted as a big-endian integer modulo three is
the group. Group zero is shadow (15 names); groups one and two are fitting
(17 and 4 names). The canonical manifest rows have SHA-256
`7f9936bde114ece33c5add6b0140bd067410f66d1399e3f0f5ea09f25b34d641`.
Names only select evaluation roles and deterministic search ordering.

The seeds are 11, 22 and 33, with two generations after a fresh per-seed
fitting-only bootstrap. Every task search uses B64, maximum complete size 12,
20,000 expansion and compiler steps, 2,000 interpreter steps, and ten process
CPU seconds including conditioning/root-allocation work. The complete physical
campaign has one 1,800 CPU-second parent/worker watchdog, including startup,
training, persistence and reconstruction. A stopped or malformed campaign is
partial and cannot pass admission.

The kernel is the new priority-capable coordinate adapter, with
`production_priority=True`, `arity_context=False`, eta exposure on, the
registered shared root policy and frozen zero DSL scorer. The uniform arm
receives the same fitted grammar but no recognition modulation; it is neutral
recognition, not a replacement for the shared fitted prior. The separately
proposed arity operator is excluded from every arm in this probe.

The library is empty throughout, no compression proposal is made, and the
common dream corpus is empty throughout. These fixed omissions make the probe
a test of failure credit with real fitting positives only. No copied all-TRAIN
bank, recognizer, grammar fit, dream, or source solution is an input. All raw
bank entries are created by this run's fitting searches and independently
verified on that fitting task's public and hidden examples. Fitting-only
grammar counts and positive recognition labels are rebuilt from this bank.
No shadow solution or trace enters it. The complete raw fitting trajectories,
public preferences, exclusion reasons, immutable source grammar snapshots,
model states and independent verification proofs are retained.

## Matched sequence and admission

Each seed first searches every fitting task with a fresh default grammar,
neutral recognition and empty bank. Extract preferences from these own
trajectories against their original grammar; independently verify each selected
root before adding it as a positive/bank entry. All fitting tasks are processed
before any shadow result can be inspected.

Generation zero fits the common grammar and prepares one common recognition
state using fitting-public feature statistics, the full observed key union,
the seed's fixed initialization and the common 80-step positive fit. Its six
prospective shadow arms, in fixed order, are predecessor, positive-only extra
80 steps, uniform, cumulative contrastive extra 80 steps, one-shot, and
fixed-seed label permutation. The predecessor is the common state with no
extra update. The one-shot is exactly generation zero's contrastive state.
All arms receive the same bank, prior grammar, zero scorer, seeds, operator
set and budgets; each performs a fresh complete candidate search. Label
permutation sorts canonical pair keys first and uses the registered seed;
an unchanged/constant-label control is explicitly uninformative.

After all three seeds finish a generation, the cumulative update is admitted
only if each seed has a strict independently verified shadow solved-set
expansion over predecessor, positive-only and uniform, with no loss against
the previous generation's admitted solved set. Missing controls, no new
preferences, missing groups or partial records veto admission. Generation
zero equality with one-shot is expected. Generation one additionally requires
a strict solved-set expansion over the retained generation-zero one-shot;
an informative permutation control must also be strictly beaten at both
generations. This is intentionally stricter than a mere residual or count gain.

Only an all-seed admitted state is retained. Rejection preserves the common
predecessor model and raw preference memory, without retaining rejected
contrastive parameters. Before generation one, each seed performs fresh
fitting searches with its retained state and previous shared bank/grammar.
Only fitting verification may expand the bank. New fitting preferences are
deduplicated against cumulative replay. The shared feature transform is
frozen from generation zero. Prior weights align by context/production key,
new keys have zero offsets, and each arm starts from the same new common
positive fit where applicable. The one-shot retains its old weights, aligned
by key with neutral new offsets; it receives no further optimizer steps.

The second admission is evidence of subsequent cumulative improvement only
if the first update was admitted, actually reused for the new fitting search,
and independently beats the retained first state in the subsequent shadow
probe on all seeds. Either rejected generation yields no loop claim. Even a
passing two-generation probe cannot establish the original RSI criteria.

## Freeze, persistence and reporting

`python -m rsi2.research.failure_credit_run --freeze PATH` writes an immutable
registration containing this configuration, grouping, and the committed Git
source revision. The implementation must be committed with no tracked changes
under `rsi2`. This command reads TRAIN task names only. It runs no search.
`--registration PATH --output DIRECTORY` verifies the revision and tracked
working tree before any worker loads TRAIN tasks. The root coordinator authorizes the actual internal
launch only after code review and independent synthetic verification; that is
not a user-permission requirement.

One append-only journal saves completed raw searches exactly once and commits
progress after every search, verification, extraction and training stage.
Public-match roots are unaccepted until an independent full public+hidden
proof completes. Search/compiler/verification counters remain exact for
completed operations; interrupted work is labelled a lower bound. Parent
reconstruction validates persisted coverage, budgets, bank provenance, proofs,
shared arm settings and admission decisions rather than trusting a worker's
terminal success message. No result auto-publishes original RSI success.
