# TRAIN-only revision: binding-role strata

Data-derived map decomposition failed both newly applicable TRAIN tasks at
64 and 640 combined attempts. Of 639 enumerated scalar components, only five
contained bound variables; none placed a binary arithmetic primitive inside a
lambda. The inherited probability prefix mostly explores fixed-first-argument
partial functions. More of the same prefix and scalar decomposition alone do
not repair this structural coverage bias.

The new generic search interleaves lambda-body production heads and each
type-compatible bound-input argument role. Heads and replacement components
come from the unchanged grammar, with shared polymorphic constraints; no task
name, handwritten target program, primitive, literal or weight is installed.
Baseline prefix 16 is followed by deterministic round-robin strata. Remaining
arguments are enumerated in their correct binder environments. Closed wrappers
must expose their prescribed binders structurally at enumeration time; this
constraint does not add programs or a task-specific score. Filtering invalid
wrappers after a huge unconstrained prefix would repeat the diagnosed bias.

A second composition applies the same scalar search to the public pointwise
projection of map-compatible tasks. The operator head is obtained by typed
enumeration. Head, scalar helper and full-root attempts share B64/B640; all
semantic helper evaluations are charged. Applicability remains a hypothesis
and every composed root must pass all original public and hidden checks.

Keep size12, expansion20,000, interpreter2,000, 10 CPU seconds/task and the
bootstrap study's aggregate 1,800 CPU seconds. Seeds11/22/33 are diagnostic
seeds; first-seed failure screening can reject an unpromising method, with
unrun seeds explicitly unknown. Structural expansion units differ between
kernels, so equal logical caps never establish equal physical effort.

Test capture, shared polymorphism, full-root accounting, semantic helper
accounting and post-call CPU veto before freezing source for TRAIN comparison.
Retain all failed pilots. Input-role coverage and extra solved tasks are
engineering diagnostics; genuine loop gain still requires learned components
to improve future verified search under common-kernel causal controls.
