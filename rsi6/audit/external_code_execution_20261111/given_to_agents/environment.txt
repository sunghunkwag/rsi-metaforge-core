Environment in which the experiment must be built and run:
- One Linux machine, 4 CPU cores, 15 GB of memory, no GPU. Python 3.13 (3.11 also installed). NumPy 2.5 and pandas are installed; other packages can be installed from PyPI (scipy, networkx, sympy, gymnasium, pddlgym, arckit are not installed but installable). raw.githubusercontent.com and huggingface.co answer; downloads must be made once, frozen into the repository with their hashes and provenance, and the system itself must not use the network at run time.
- No language model can be called from Python code: there is no model API and no local model. Language-model agents exist only as the developers and reviewers of the code (an orchestrating session that can start sub-agents); they are not a component the running system can call. Amendment A1 of the repository (a local language model as an untrusted proposer inside the runtime) is drafted and NOT enacted.
- Budgets must be counted in countable units (verifier calls, candidate evaluations), not in seconds. Runs must be reproducible from seeds; the repository's standard is two runs with identical digests.
- Wall-clock available: hours to a few days of this one machine. A full registered experiment (all arms, all generations, all test tasks) should fit in about 8 to 12 hours; development experiments in minutes to an hour.
- Evaluating one candidate answer against a puzzle's verifier costs tens of microseconds to milliseconds in Python; a time limit per call is needed because verifiers can be slow on large candidates.
