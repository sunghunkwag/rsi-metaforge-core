### What the project provides

RSI MetaForge Core is a standard-library-only Python runtime for measuring whether a program can propose, test, and retain improvements under fixed evaluation conditions.

The repository currently provides:

- one-command execution without an installation or external model API;
- 286 executable tests;
- quick and full-evidence GitHub Actions workflows;
- deterministic two-run replay checks;
- sealed held-out evaluation and rollback records;
- pre-registered predictions with misses retained;
- committed result documents for stack-VM, file-processing, formal-reasoning, and self-generated-task experiments;
- explicit claim boundaries and documented negative results.

The project is experimental. Its value is the reproducible public instrument and evidence trail, not a claim of general intelligence or production readiness.
